# Scripture Path Maze

An interactive bilingual Bible journey game for **Learn Bible with Fun**.

## Biblical scope

Paul and Barnabas’ first missionary journey, based on **Acts 13–14**.

## Planned game experience

- English and Tamil
- Easy, Medium and Hard modes
- Illustrated Mediterranean game world
- Animated ship and land travel
- Correct destination: flag, celebration and learning card
- Wrong destination: clear visual feedback without revealing the answer
- Responsive mobile, tablet and desktop layout
- Installable Progressive Web App foundation

## Content rule

Every route, place, event and learning card must be checked against Acts 13–14 before publication.
